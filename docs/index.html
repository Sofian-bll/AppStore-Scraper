Features

36-Country Scraping

Fetch in-app purchase prices from Apple's App Store across 36 countries simultaneously.

CSV Export

Structured data export with country, name, price, price_formatted, and currency columns.

Progress Tracking

Real-time progress bar showing country-by-country fetch status with completion percentages.

Currency Conversion

Automatic EUR conversion via live exchange rates with intelligent caching for performance.

Error Resilience

Graceful handling of unavailable apps, API timeouts, retries, and missing data per country.

Zero Config

Edit one variable to target any App Store app. Modify the country list as needed.

Quick Start

Get scraping in under 60 seconds.

git clone https://github.com/Sofian-bll/App-Store-Price---Scraper-v2.git
cd App-Store-Price---Scraper-v2
pip install -r requirements.txt
python Request2.py
