Features

Everything needed to scrape, structure, and analyze App Store pricing data.

36-Country Scraping

Fetch in-app purchase prices from Apple's App Store across 36 countries simultaneously with real-time progress tracking.

CSV Export

Structured data export with country, name, price, price_formatted, and currency columns. Ready for analysis in Excel or pandas.

Currency Conversion

Automatic EUR conversion via live exchange rates with intelligent caching to avoid redundant API calls.

Error Resilience

Graceful handling of unavailable apps, API timeouts, retries, and missing data per country. Never crashes on edge cases.

Zero Config

Edit one variable to target any App Store app. No API keys, no authentication, no external services needed.

Quick Start

Get scraping in under 60 seconds.

Setup 
git clone https://github.com/Sofian-bll/AppStore-Scraper.git
cd AppStore-Scraper
pip install -r requirements.txt
Run 
# Scrape prices across 36 countries
python Request2.py

# Convert all prices to EUR
python price_converter.py
